工具下载

uv 是推荐的 Python 包管理器，支持 pip install 和 python 解释器安装。

uv-installer.sh（Linux/macOS） uv-installer.ps1（Windows）

安装后直接可用，无需额外配置镜像地址。

使用方式

安装 Python 包：

uv pip install <包名> --index-url

或配置为默认源：

export UV_DEFAULT_INDEX=

安装 Python 解释器（如 3.12）：

export UV_PYTHON_DOWNLOADS_JSON_URL=
uv python install 3.12

临时使用：

pip install <包名> --index-url  --trusted-host

或设为默认：

pip config set global.index-url 
pip config set global.trusted-host
